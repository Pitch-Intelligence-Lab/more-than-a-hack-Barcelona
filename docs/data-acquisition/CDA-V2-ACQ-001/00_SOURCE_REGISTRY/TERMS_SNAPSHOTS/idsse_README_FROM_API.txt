## Description


	
		
	
	
		IDSSE — Sportec Open Tracking & Event Data
	

Mirror of the IDSSE dataset, originally hosted on Figshare, re-hosted here for stable and fast access via kloppy and related tools.

	
		
	
	
		Contents
	

7 complete matches from the German Bundesliga season 2022/23 (1st and 2nd division), collected by Sportec Solutions using TRACAB optical tracking technology.
Each match includes:

Tracking data — position of all players and the ball at 25 fps
Event data — synchronized match events… See the full description on the dataset page: https://huggingface.co/datasets/pysport/idsse-data.

## Retrieval note

The original Hugging Face hostname was not resolvable from this network. The dataset was retrieved through the official-repository mirror endpoint https://hf-mirror.com, and every LFS object was checked against the official oid recorded in the pinned repository tree.
